# Security policy

Please do not report suspected vulnerabilities in a public GitHub issue. Until a dedicated security contact is configured, report them privately to the repository owner through GitHub's private vulnerability reporting feature, if enabled.

Include a concise impact summary, affected version or commit, and safe reproduction details. Do not include credentials, production data, or exploit payloads. Maintainers will acknowledge reports within five business days and coordinate disclosure after a fix is available.

Supported versions are the current main branch and the latest published release.
